Lambda Function Configuration
Lambda Function Details
Please provide a valid Lambda function name (alphanumeric, hyphens, underscores).
Please provide a Lambda handler (file.function_name).
Timeout must be between 1 and 900 seconds.
Memory must be between 128 and 10240 MB.
If left empty, a default code template will be generated based on your selected runtime.
IAM Role and Policy Configuration
If left empty, a role name will be generated based on your Lambda function name.
If left empty, a default policy with permissions for CloudWatch logs and X-Ray will be used.
Schedule Configuration
Hour must be between 0 and 23.
Minute must be between 0 and 59.
The Lambda function will be scheduled to run daily at 8:00 AM
API Usage

You can also generate the CloudFormation template programmatically using the API endpoint:

POST /api/generate
Content-Type: application/json
